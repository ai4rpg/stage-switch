# @ai4rpg/dsh-ui-sidebar-stage

[English](README.md) | 中文

本包提供 dsh Web 客户端右侧栏的**阶段标签页**：以 Atlas 式视图展示运行 `@ai4rpg/dsh-stage-switch` 的会话当前处于阶段旅程的哪里、每个阶段花了多少，以及下一步能去哪里。

## 工作原理

- **本包是纯 UI 插件。** 它向右侧栏注册阶段标签页，并附带标签页实时标题与输入框上方的阶段胶囊。它没有自己的 Host 半，也不发起 RPC。
- **优先使用 Host 的阶段视图，读不到时回退到会话事件窗口。** 挂载了 stage-switch 且本会话已有阶段记录时，标签页显示 Host 提供的阶段目录、旅程与计数；否则在客户端折叠已加载的事件窗口。空闲与恢复会话看到同样的视图。
- **只有使用 stage-switch 的会话才会显示标签页。** 没有阶段记录的会话看到空状态，即使同一 runtime 的其他预设挂载了该插件。
- **Atlas 视图以当前阶段为中心。** hero 显示阶段目录序号、标签/别名、instruction、本阶段活跃时长与可选的上下文压力 gauge；计时只累计回合时间，会话空闲时暂停。指标行显示当前阶段的消息、工具调用与 token。下方旅程列出访问记录、当前节点，以及目录中**尚未访问**阶段的未来节点。访问过的阶段会转到上方可切换的历史行；切换面板始终提供完整路线。所有已记录访问都会保留；旅程在标签页内部独立滚动，长历史不会把 hero、指标或切换按钮挤出侧栏。面板矮到放不下固定区块时，标签页整体滚动，切换按钮始终可达。亮暗主题、双语与 reduced-motion 均支持。
- **环境化表面让阶段在标签页之外也可见。** 标签页标题显示当前标签与身份色点；输入框上方的胶囊显示标签、活跃时长与 live 状态，点击打开标签页。两者读取同一个 Host 视图；视图缺失时，标题回退到默认标签，胶囊不渲染。
- **可以直接在标签页内切换阶段。** 命令面板（`⌘K` / `Ctrl K`，或「切换阶段」按钮）在目录已知时列出完整目录（回退时列出访问过的阶段），支持搜索、键盘导航与自定义阶段名。每次选择都通过会话的 command 面提交 `/stage <name>`；尚未落地的请求显示「已请求」，失败则显示命令自己的错误信息。

## 部署

标签页模块从 **host 层行**加载——预设作用域的行永远不会被扫进浏览器 roster。tavern 预设 bundle 插入该行（active）；无预设部署在 tavern-stages 的 host 补丁里列出它（与其余行一起 disabled，需要时一起启用）。

尚无阶段记录的会话显示标签页的空状态；如果该会话的预设从未挂载 stage-switch，尝试切换会得到命令的不可用提示。本包声明 `engines.dsh`（`>=0.2.0-rc.2 <0.3.0-0`），DSH 会在加载前拒绝不兼容的运行时；本包没有 peerDependencies。

## 开发

```sh
npm run typecheck
npm test
npm run build
```

`npm run build` 产出 host 入口与浏览器闭包 bundle。

可选的 `npm run test:integration` 会把插件挂上本地 dsh 源码 checkout 的**生产** slot 机器（真 SlotRegistry/renderer、真会话 fixture）。需要与本包 devDependencies 同版本线的 dsh checkout（版本漂移时直接报错），其余场合（含 CI）一律跳过——默认套件保持自足。

> `@ai4rpg/dsh-stage-switch` 开发依赖为 `^0.2.0`，即本包折叠契约所针对的发布。较新的 stage-switch 以兼容方式新增字段，标签页也为较旧宿主保留回退。在本仓库内，workspace 会把该名字解析到兄弟包源码；从 npm 安装则拿到同一区间的已发布版本。发布时 stage-switch 先行；改动这个钉住关系意味着本包要发新版本。
